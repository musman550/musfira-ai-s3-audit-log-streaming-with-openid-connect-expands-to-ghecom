## Overview

S3 audit log streaming with OpenID Connect expands to GHE.com

S3 audit log streaming with OpenID Connect expands to GHE.com is a new feature that allows organizations to stream enterprise audit logs to Amazon S3 using OpenID Connect (OIDC) on GitHub Enterprise Cloud with data residency (GHE.com). This expansion enables a more seamless and secure way to collect and store audit logs, ensuring compliance with regulatory requirements and protecting sensitive data. By leveraging OpenID Connect, GitHub Enterprise Cloud with GHE.com provides a secure and scalable way to stream audit logs, making it easier to meet data residency requirements and maintain audit trail integrity.
